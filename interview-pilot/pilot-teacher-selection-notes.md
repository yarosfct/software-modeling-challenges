# Teacher Pilot Selection Notes

Use this note to decide which teacher guide to take into the next pilot interview.

## Guide A - Comparable Revision

File: pilot-teacher.md

Choose this version when:

* you want continuity with the current pilot structure
* you want cleaner RQ traceability during analysis
* you expect the interviewee to be reflective and willing to answer broader course-design questions

Main characteristics:

* recognisable section flow
* less overlap than the previous version
* still broad enough to support cross-case comparison
* safer if you want to compare directly with earlier pilot data

## Guide B - Focused High-Yield Version

File: pilot-teacher-focused.md

Choose this version when:

* you want richer evidence in a limited time window
* you want to prioritise concrete incidents over general descriptions
* you want to test the strongest hypotheses emerging from current lecturer coding and memos

Main characteristics:

* more direct and more diagnostic
* less time spent on generic background
* stronger focus on starting barriers, worked examples, quality judgement, transition between modelling families, tools, and workload constraints
* better if the goal is to refine the thesis argument quickly

## Guide C - Gap-Filling Version (current recommendation for new interviews)

File: pilot-teacher-guide-c.md

Choose this version when:

* you are conducting interviews after the first coding cycle (S1-S3, L1-L4)
* you want to fill gaps: AI and assessment, scale-dependent pedagogy, shy students, multi-family transitions, integrated tooling, RE/socio-technical practice

Main characteristics:

* extends Guide B with Q8-Q13 gap blocks (use selectively)
* adds explicit probes on AI, class size, and passive students
* still incident-first with time triage

## Practical recommendation

For **new** interviews after the first analysis cycle, use **Guide C**. Use Guide B for shorter diagnostic sessions. Use Guide A for continuity with the earliest pilot structure.

## Shared interviewer reminders

* Do not try to ask every probe.
* Ask for one concrete incident whenever the teacher becomes too abstract.
* If a strong theme emerges early, stay with it and trim later sections.
* Semi-structured does not mean unfocused: follow interesting topics only when they clearly help answer the thesis questions.
