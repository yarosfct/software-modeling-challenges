TITLE: Standardizing the project domain balances fairness, motivation, and integrity
DATE: 09/04/2026
INTERVIEW / SOURCE: Lecturer interview 3
RELATED RQ(s): 
RELATED CODES: common domain for fairness and comparability; motivating story around project domain; student-chosen domains would be unfeasible; domain choice creates uneven complexity; copying risk in open domain choice
CATEGORY / THEME: Course design / assignment design

1. What is happening here?
The lecturer uses one shared project domain for the whole class each semester. That choice supports fairness and comparability, but the lecturer still tries to motivate students by wrapping the domain in an engaging story.

2. Why is this analytically important?
This shows that assignment-domain choice is both a pedagogical and an assessment decision. Domain selection affects motivation, fairness, complexity control, and even the risk of copying.

3. What seems to be the underlying issue?
Open domain choice could increase ownership, but in a large course it would create major problems of uneven difficulty and academic integrity.

4. What evidence supports this?
- "one common domain for the whole class each semester"
- "partly for fairness and partly so the work remained comparable"
- "I usually tried to build a motivating story around the domain"
- "that would not be feasible with 300 students"
- "some would choose very simple domains and others very complex ones"
- "would simply copy them"

5. What tensions / contradictions appear?
Standardization helps fairness, but it limits personalization. The lecturer compensates by trying to make the common domain more engaging.
