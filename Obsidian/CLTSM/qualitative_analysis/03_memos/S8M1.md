# S8M1 — modelling arrived as a project requirement first

Superseded 30 September 2026 for chronology only. The underline–pencil–pen routine is T011, later class exercises, not a routine already in place on the bachelor’s project. The supported project claim is that S8 did not know how to use the notations. “Required before taught” overstates that. S8 later confirmed there was no group project in the software modelling courses; the group-project remark in T005 was a slip. The idea paragraph is the memo as first written.

## Idea
At ISEL, S8 first had to produce UML/RE diagrams in the bachelor’s project without knowing the notations; the master’s Software Engineering course was the first proper teaching. By then a homemade process was already in place: underline requirements, pencil sketch, pen. Teacher examples mainly taught notation, not the expected answer.

## Why it matters
Starting without a taught path (CAT1) can happen as a capstone requirement, not only as a first lab freeze. Later examples still help, but they arrive after students have already invented a sketching routine (CAT4).

## Open question
Do other project-heavy programmes produce the same “required before taught” pattern, or is this specific to ISEL’s practical bachelor?
