# L1M4 — switching notation family shifts the modelling frame

- Case: L1
- Codes: L1-C13, L1-C12, L1-C01
- Turns: T041, T043, T045, T039

## Idea
Within one course, students move from BPMN through SysML/requirements work toward feature models. L1 finds the jump to modelling a product family—optional vs mandatory features—not the notation syntax alone, hardest. He sees students resist the new frame even after board explanations; practical show-and-tell exposes the gap repeatedly when he must explain "No, it should not be modelled like this."

## Why it matters
"Interference between models" is a socio-technical sequencing issue: prior system-modelling habits collide with a new semantic context. Expressive languages (BPMN) add load before that frame shift.

## Open question
Do students name the same feature-model mindset shift, or only BPMN/notation issues in earlier courses?
