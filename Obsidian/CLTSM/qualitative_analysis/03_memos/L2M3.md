# L2M3 — tools motivate through code and guardrails

- Case: L2
- Codes: L2-C11, L2-C12, L2-C13
- Turns: T037, T039, T045, T047

## Idea
L2 uses a complete multi-diagram tool with short onboarding videos. Code generation pulls students toward modeling, while typed constraints catch syntax and classic mistakes. One broad tool is preferred over switching between family-specific environments.

## Why it matters
Tool choice is pedagogical: it couples student motivation (code path) with error prevention and preparation for industry-grade complexity.

## Open question
When code generation is unavailable, do the same students disengage—or shift motivation to another artifact (tests, deployment views)?
