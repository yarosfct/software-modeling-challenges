TITLE: Tooling is pedagogical support, not just implementation medium
DATE: 19/03/2026
INTERVIEW / SOURCE: Lecturer interview
RELATED RQ(s): RQ2, RQ3
RELATED CODES: drawing tool vs modelling tool; tool-supported checking; lack of semantic feedback in tools; need for free tools; tool usability barrier; guided educational modelling tool
CATEGORY / THEME: Tooling / desired supports

1. What is happening here?
The lecturer strongly differentiates between drawing tools and modelling tools. Useful tools are those that provide checking, feedback, and support for valid model construction.

2. Why is this analytically important?
This supports the argument that modelling tools shape the learning process itself. They are not neutral containers.

3. What seems to be the underlying issue?
Students need tools that support semantics, validity, and guided action. Cost and usability are also important constraints.

4. What evidence supports this?
- “draw.io... its just a drawing tool its not a modelling tool”
- “tools that do some checking”
- “free tools”
- “usability was really bad and we exchanged that”

5. What tensions / contradictions appear?
Tools are valued, but class time and tool access limit their use.

IMPLICATIONS:
A guided modelling environment with checking, templates, next steps, and educational feedback seems aligned with lecturer needs.
