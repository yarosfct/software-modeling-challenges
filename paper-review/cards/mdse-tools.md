# Liebel et al. — MDSE tools and UML perception

**Use:** Tools, course design, motivation.

## Design
Multi-case study of modelling courses (US/Sweden) using tools such as Umple and Papyrus; surveys + qualitative data on perception of tools vs UML.

## Findings that matter
- Tool perception depends on **usability**, **course role of modelling**, project domain, and support — not tool brand alone.
- Industrial tools (e.g. Papyrus) can demotivate when used for precise MDA without reliable support.
- Broader MBE use (requirements/analysis/communication) sustains more positive UML perception.
- Education needs **constructive, education-tailored feedback**, not only compiler-like errors.
- Educational tools need pedagogy-aligned features more than full industrial stacks.

## Thesis takeaway
Supports claims about tool friction and feedback quality in modelling education; align with interview evidence on tools and progressive guidance.
